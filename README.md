# SignalCopy Dashboard

Build a premium, modern marketing landing page for a product called "SignalCopy".

IMPORTANT:
This is a MARKETING LANDING PAGE, not a product documentation page.

The visitor should understand the product very quickly:

1. What SignalCopy is
2. Who it is for
3. How to get started
4. What they can do with it
5. How much it costs
6. How to start

DO NOT explain the internal technical architecture.

DO NOT explain:
- AI parsing internals
- Signal validation logic
- Risk engine
- JSON
- APIs
- Backend architecture
- VPS networking
- MT5 implementation details
- Telegram APIs
- Technical execution pipeline

The landing page should sell the simplicity of the product.

==================================================
PRODUCT
==================================================

Product name:

SignalCopy

Core positioning:

"SignalCopy is a desktop/VPS application that lets you monitor Telegram trading signals and automate MT5 trading, while giving you complete control from anywhere through our web dashboard."

Target audience:

People who follow Telegram trading signals and want to automate their MT5 trading workflow.

The user can run SignalCopy on:

- Their own Windows PC
OR
- Their own Windows VPS

After installing the SignalCopy application, the user can manage and control the connected machine from anywhere through the SignalCopy web dashboard.

Basic setup:

Your Windows PC / Windows VPS
        ↓
Install SignalCopy App
        ↓
Connect your SignalCopy account
        ↓
Open SignalCopy Web Dashboard
        ↓
Control everything from anywhere

Telegram setup:

Connect Telegram
        ↓
Select Sources
        ↓
Start Monitoring

MT5 is optional.

If the user connects MT5, SignalCopy can automate trade execution based on the Telegram signals they monitor.
